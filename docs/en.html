From mixed XRD to phase-resolved patterns and MP structure candidates

An end-to-end workflow for multiphase powder X-ray diffraction: decompose a mixture, estimate phase activity, retrieve candidate Materials Project structures, and compare experimental profiles with theoretical Bragg peaks.

Overview

XDecomposer is forked from Licht0812/XDecomposer. This repository adds a deployable FastAPI service, MP structure retrieval, an XRDbench demo, CIF export, and an interactive analysis interface.

Important: the neural network predicts phase-resolved XRD profiles. The returned mp-id is obtained afterward by matching each predicted profile against the currently loaded reference library; it is not a crystal structure generated directly by the model.

Weights and structure database

Download the published checkpoints and database from GitHub Releases. The default runtime paths are:

XDecomposer/
├──  checkpoints/
│   ├── pretrain/best_model.pt
│   └── sepration/latest.pt
├── MP500.db
└── api/main.py

Override paths with XDECOMPOSER_CHECKPOINT, XDECOMPOSER_MAE_CHECKPOINT, XDECOMPOSER_MATERIALS_DB, and XDECOMPOSER_REFERENCE_CACHE. The default reference-bank size is 500, configurable through XDECOMPOSER_MAX_REFERENCES.

Architecture

The model combines a convolutional encoder/decoder, Transformer features initialized from a masked autoencoder, K learned phase queries, an activity head, FiLM conditioning, and skip connections. Soft masks constrain each output profile to the support of the input mixture.

ComponentRole
Masked autoencoderLearns peak shapes and global diffraction context from single-phase profiles.
Phase queriesExtract K candidate phase representations and activity logits from the shared latent sequence.
FiLMApplies query-specific γ and β modulation to separate phase-specific features.
DecoderRestores 1D diffraction signals using skip connections and predicted masks.

Training workflow

1. MAE pretraining

Single-phase patterns are split into overlapping patches (length 50, stride 25). Around 70% are masked; the encoder learns to reconstruct them using weighted L1, cosine, and derivative consistency terms.

conda create -n xdecomposer python=3.10
conda activate xdecomposer
pip install -r requirements.txt
bash scripts/bash_train/run_pretrain.sh

2. Multiphase decomposition

The online mixing dataset samples 2–4 phases and random fractions. Permutation-invariant training chooses the lowest-loss assignment between predicted output slots and target phases. The loss combines peak-weighted L1, SI-SDR, root-space gradient geometry, mixture consistency, and activity supervision.

bash scripts/bash_train/run_xdecomposer.sh --gpus 0,1 --name main

Run the API and web interface

python -m uvicorn api.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000/ for the interactive UI. It accepts pasted or CSV/TXT XRD data, exports JSON/CSV, downloads CIF files, loads an XRDbench multiphase example, and supports boxed zoom in every main chart.

Programmatic request

curl -X POST 'http://127.0.0.1:8000/v1/decompose?top_k=3' \
  -H 'content-type: application/json' \
  -d '{"intensities":[0,0.2,1.0,0.1,0]}'

Use two_theta when measured angles are available. Otherwise intensities are assumed to be uniformly sampled between 10° and 80°. Input is interpolated to 3,500 points and max-normalized before inference.

Interpret the results

Each phase includes active, activity_probability, mp_id, match_score, top alternatives, and a CIF download URL. In the UI, click a phase to overlay its theoretical Cu Kα Bragg sticks on the imported experimental profile. Both use the same y=0 baseline.

The XRDbench demo includes known phase IDs and fractions. It is useful for testing the full request path; retrieval quality depends on whether the ground-truth structures are present in the active candidate library.

Scope and limitations

  • The default calculation uses Cu Kα and a 10–80° 2θ range.
  • Only structures in the active reference bank can be returned; an out-of-library material is mapped to its nearest available candidate.
  • Background, peak shifts, preferred orientation, amorphous content, and instrumental broadening can reduce reliability.
  • Use this as a candidate-screening tool; confirm assignments with expert analysis and Rietveld refinement.
