项目概览

Asterbin-XDecomposer 是从 Licht0812/XDecomposer fork 而来，并在此仓库中补充了可部署的 FastAPI 推理接口、基于 MP500.db 的结构检索流程及本说明页面。上游项目的目标是对整条多相 XRD 图谱进行盲源分解，而非仅做峰位搜索或物相分类。

3500默认统一 XRD 采样长度
最多 4 相当前发布分解 checkpoint 的输出槽位数
MP500用于候选结构检索的 ASE 数据库

工作流：模型先预测每一个相的分解曲线；随后 API 将曲线与 MP500.db 中结构计算得到的理论 XRD 做余弦相似度检索。因此 mp-id 是当前候选库中的匹配结果，不是模型直接生成的晶体结构。

下载模型权重与结构库

分解 API 需要两个 checkpoint 与一个材料数据库。它们已发布在 Asterbin-XDecomposer Releases。下载后在仓库根目录保留以下相对路径；当前仓库中的目录名为 checkpoints（注意前导空格）。

Asterbin-XDecomposer/
├──  checkpoints/
│   ├── pretrain/best_model.pt       # MAE 预训练配置/编码器权重
│   └── sepration/latest.pt          # 多相分解模型权重
├── MP500.db                         # 含 mpid 的候选晶体结构库
└── api/main.py                      # FastAPI 服务

也可不使用默认位置，而是通过环境变量指定绝对路径：

export XDECOMPOSER_CHECKPOINT=/data/latest.pt
export XDECOMPOSER_MAE_CHECKPOINT=/data/best_model.pt
export XDECOMPOSER_MATERIALS_DB=/data/MP500.db

启动时会对候选结构计算 Cu Kα 理论谱并构建检索参考库。API 默认使用 500 条结构（XDECOMPOSER_MAX_REFERENCES=500）并缓存结果；提高该值会明显增加启动时间与内存占用。

模型架构

分解网络由一维卷积编码/解码器、从 MAE 初始化的 Transformer，以及相查询（phase query）和 FiLM 调制组成。当前发布配置以 4 个输出槽位为例，每个槽位对应一个可能存在的物相。

组件职责

组件作用
Masked Autoencoder（MAE）在单相谱上学习局部峰形与全局衍射上下文；编码器包含 patch embedding 和 4 层 Transformer。
1D CNN 编码器/解码器提取并还原连续衍射信号。解码时使用 skip connections 保留峰形细节。
PhaseQueryHead用 K 个可学习 query 从共享特征中取出 K 个潜在物相，同时产生每相 activity logit。
FiLM由 query 生成 γ、β，对 token 表征进行条件调制，使不同相获得不同的特征通道。
Soft mask 输出解码器预测相掩码，再与输入混合谱相乘，以保持输出与原始谱的物理支持区域一致。

模型训练

阶段一：单相 MAE 预训练

训练数据为单相 XRD。输入谱被切为长度 50、步长 25 的重叠 patch，随机掩蔽约 70% patch，模型从未掩蔽上下文重建它们。训练损失由峰强度加权 L1、余弦相似度和一阶导数一致性组成，使模型同时学习峰强、谱形及峰边缘。

conda create -n xdecomposer python=3.10
conda activate xdecomposer
pip install -r requirements.txt

# 先修改 configs/paths.sh 中 PATH_DATA_SINGLEPHASE
bash scripts/bash_train/run_pretrain.sh

阶段二：在线混合与多相分解

OnlineMixingDataset 从单相库采样 2–4 个相，使用随机权重在线合成混合谱。分解模型不固定输出槽位与真实相的顺序，因此采用 permutation-invariant training（PIT）：在所有输出/目标排列中选取损失最小的匹配。

  • 相级重建：峰强度加权 L1；
  • 分离质量：SI-SDR 项；
  • 几何约束：在平方根强度空间的一、二阶梯度损失；
  • 混合一致性：按混合权重加总的预测谱应接近输入混合谱；
  • Activity：用每个槽位是否含真实相监督相存在概率。
# 需要先完成 MAE 预训练，或在 paths.sh 配好 PATH_CKPT_PRETRAIN
bash scripts/bash_train/run_xdecomposer.sh --gpus 0,1 --name main

训练脚本支持 DDP、多 GPU、断点续训与余弦学习率调度。常用路径、数据集位置和 checkpoint 位置集中在 configs/paths.sh。

API：输入 XRD，返回 mp-id

API 文件为 api/main.py。安装依赖并在项目根目录启动：

pip install -r requirements.txt
uvicorn api.main:app --host 0.0.0.0 --port 8000

打开 http://127.0.0.1:8000/docs 可查看 FastAPI 自动生成的交互式 OpenAPI 页面。服务启动完成后，GET /health 返回 {"status":"ok"}。

请求：POST /v1/decompose

intensities 为必填的一维强度数组，最少两个点。two_theta 可选；若省略，服务假定输入在 10–80° 之间等间隔采样。无论原始长度是多少，API 都会插值至 3500 点、裁剪负强度并做最大值归一化。

curl -X POST 'http://127.0.0.1:8000/v1/decompose?top_k=3' \
  -H 'content-type: application/json' \
  -d '{
    "two_theta": [10.0, 10.1, 10.2, 10.3, 10.4],
    "intensities": [0.0, 0.15, 1.0, 0.20, 0.0]
  }'
参数位置含义
intensitiesJSON body，必填测得的 XRD 强度；必须是有限数值，且至少含一个正值。
two_thetaJSON body，可选以度为单位、严格递增；长度必须与 intensities 一致。
top_kquery，默认 5每个分解相返回的候选 mp-id 数，范围 1–20。
include_patternsquery，默认 false设为 true 时，返回每个相完整的 3500 点分解谱。

结果解释

{
  "xrd_length": 3500,
  "two_theta_range": [10.0, 80.0],
  "phases": [
    {
      "phase_index": 0,
      "active": true,
      "activity_probability": 0.91,
      "mp_id": "mp-1001824",
      "match_score": 0.87,
      "alternatives": [
        {"mp_id": "mp-1001824", "match_score": 0.87},
        {"mp_id": "mp-...", "match_score": 0.81}
      ],
      "xrd": null
    }
  ]
}
  • active：activity_probability ≥ 0.5 的便捷布尔标记。低活性槽位通常可忽略。
  • match_score：分解谱与参考理论谱的余弦相似度，越高表示在当前 MP500 候选库中越相近。
  • alternatives：建议结合前几名、化学成分和实验条件共同判断，而非只依据第一名。

使用边界与复现建议

  • 模型和参考库统一使用 10–80° 的 Cu Kα 理论 XRD；请尽量将实验谱校准到兼容的 2θ 范围与辐射条件。
  • 当前 API 只在 MP500.db 所含候选结构中检索，库外结构仍会被映射到“最接近”的库内候选。
  • 峰位偏移、择优取向、荧光背景、无定形组分和未知仪器展宽会降低分解与检索可靠性。建议先做背景扣除、波长校正和必要的峰位校准。
  • 该服务用于候选结构筛选与研究辅助，不应替代 Rietveld 精修、化学分析或人工晶体学确认。
